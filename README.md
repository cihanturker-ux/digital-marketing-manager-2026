# Digital Marketing Manager 2025

## Kurulum Talimatları

Otomatik kurulum Node.js'i algılayamadıysa, oyunu başlatmak için lütfen terminalde şu komutları çalıştırın:

1.  **Bağımlılıkları Yükle**:
    ```bash
    npm install
    ```

2.  **Oyunu Başlat**:
    ```bash
    npm run dev
    ```

## Özellikler
- **Teknoloji Yığını**: React, Vite, Three.js, Zustand.
- **Tasarım**: Premium Aydınlık Mod.
- **Oynanış**: Dijital Pazarlama için Football Manager tarzı simülasyon.
